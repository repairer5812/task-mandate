비밀번호를 건넬 때와 무엇이 다른가요

온라인 민원이 어려운 분은 지금 가족에게 공동인증서나 비밀번호를 건넵니다. 위임장은 맡긴 일만 하도록 범위를 정합니다.

기존 표준으로 만든 오픈소스입니다

웹사이트는 발급자에게 묻지 않고 위임장을 직접 검증합니다. 새 표준을 만들지 않고 아래 표준에 헤더 하나와 클레임 몇 개를 더했습니다.

  • SD-JWT VC위임장 형식. 본인 키로 서명합니다.
  • RFC 9421 HTTP 메시지 서명IETF Web Bot Auth 초안의 태그를 붙여 요청마다 서명합니다.
  • Ed25519본인 키와 에이전트 키.
